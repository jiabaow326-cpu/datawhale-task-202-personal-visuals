# 可复用提示词模板

## 先把模糊需求拆成简报

```text
请把我的需求转成一份图片设计简报，不要马上生成图。
用途：[头像/贺卡/海报/纪念图]
受众和情境：[填写]
我说的“想要好看”是：[偏好的感觉/已有约束]
请输出：主体、关键细节、构图/视角、风格/材质、色彩/光线、画幅比例、文字留白区、必须出现、不得出现、待确认问题。
不要猜姓名、真人外貌、品牌、地标或未提供的生活经历。若信息冲突，列出冲突并等我选，不要自行决定。
```

## 用确认后的简报生成

```text
用途：[填写]
画布：[比例与方向]
场景/背景：[填写]
主体：[填写]
构图与视角：[填写]
风格、材质、色彩、光线：[填写]
文字安全区：[位置和留白面积]
必须保留：[填写]
避免：[文字错字/多余物件/真人/品牌等]
请先生成一张无字底图；画面里不要出现字母、数字、标志或水印。祝福语后续另行排版。
```

## 按审稿结果做单变量迭代

```text
保持这张图的主体、风格、颜色和光线不变，只修改：[一个具体问题]。
验收标准：[可见的具体变化]
不要加入未提及的人物、文字、品牌或新物件。仍保留：[画幅比例、关键主体、其他不变项]
```

## 生成后自检

```text
请按已确认简报审核这张图：主体、构图、风格、比例、文字留白、限制项。只列出可见证据；不符合就给一条最小修改指令，不要改动其他已通过部分。
```
