# 个人视觉简报模板

先用文字回答，再把简报交给图片工具。未提供的信息写“待决定”，不要让 AI 猜真实姓名、肖像、地点或品牌。

| 项目 | 我的决定 |
|---|---|
| 图片用途 | [头像 / 贺卡 / 海报 / 纪念图] |
| 主要受众与使用情境 | [填写] |
| 主体（只选 1–2 个） | [填写] |
| 主体动作/关系 | [填写；非人物作品可略] |
| 关键细节 | [最多 3 项] |
| 构图与视角 | [近景/俯视/主体偏左等] |
| 风格与材质 | [水彩/纸艺/摄影等] |
| 色彩与光线 | [填写] |
| 画幅比例/方向 | [例如 4:5 竖版] |
| 留白/文字区 | [位置、面积、对比度] |
| 必须出现 | [填写] |
| 不得出现 | [无姓名、无品牌、无文字等] |
| 参考素材与授权 | [无 / 已确认授权；说明来源] |
| 成功检查点 | [视觉焦点、尺寸、留白、无错误字等] |
