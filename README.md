# U56 个人视觉作品生成：从“好看一点”到可复用图片简报

这是一份零基础的生日贺卡视觉方案教程。人物、称谓、场景和偏好都为虚构练习；没有真人照片、姓名、品牌或受版权保护的参考图。最终图片由生成工具原创生成。

## 交付

- `tutorial/个人视觉作品生成实操教程.md`：五步教程，每步包含缘由、动作、材料、AI 提示词和完成标志，结果逐步衔接。
- `materials/`：模糊原始需求、当前版/替代旧版、重复件、矛盾素材和错误 AI 草稿。
- `templates/`：可复用视觉简报表和提示词模板。
- `results/draft-v1.png`：初稿；`results/final-v2.png`：按审稿清单迭代后的最终图。
- `results/prompts_v1_v2.md`：两版生成提示词与迭代说明。
- `reference/参考作品与陷阱核验.md`：需求核对表、逐条陷阱答案、最终作品验收记录。

## 样例场景

目标：为虚构的春日生日场景制作 4:5 竖版贺卡底图。视觉主体是温室与小蛋糕；右上角留出干净留白，真实祝福文字后续在排版工具中添加。本例刻意不让图像模型画字，避免错字影响可用性。

## 安全与素材边界

不要直接上传真实家庭照片、孩子图像、个人信息或未获授权的他人作品。需要做真实人物肖像或使用第三方图片时，先确认相应授权；本包使用虚构场景且不含参考图。生成图片中如需可读文字，建议另用文字工具排版并人工校对。
